<h1 align="center">STORM PS4 PKG INSTALLER</h1>

## **О проекте**
**STORM PS4 PKG INSTALLER** — высокопроизводительное нативное homebrew-приложение для игровой консоли Sony PlayStation 4, предназначенное для удаленной установки игр, обновлений, дополнений (DLC) и тем оформления в формате PKG по локальной сети и с внешних USB-накопителей.

Приложение напрямую взаимодействует с системной службой фоновой загрузки Orbis OS (BGFT — Background File Transfer) и системным инсталлятором пакетов, обеспечивая максимальную скорость скачивания, стабильность работы в фоновом режиме и полный контроль над очередью задач.

## **Происхождение и базовая платформа**
Проект разработан как глубокая нативная эволюция оригинальной утилиты **Remote Package Installer (RPI)** от разработчика **flatz**, с полным переходом на собственный высокоэффективный сетевой движок, многоязычный графический интерфейс Scene2D с аппаратным выводом кадров, поддержку TrueType-шрифтов Century Gothic и расширенный протокол управления очередью.

## **Технологический стек**
- **Язык программирования**: C++ (стандарт C++17)
- **Целевая платформа**: Sony PlayStation 4 (Orbis OS, FreeBSD 12 ELF)
- **Инструментарий сборки**: OpenOrbis PS4 Toolchain, Clang / LLVM, LLD Linker
- **Графический рендеринг**: Аппаратный прямой кадровый буфер VideoOut, Direct 2D Rendering Engine
- **Шрифтовая подсистема**: stb_truetype, встроенный TrueType-шрифт Century Gothic с поддержкой Unicode UTF-8 и кириллицы
- **Графика и текстуры**: stb_image, нативная подсистема декодирования PNG и кэширования иконок
- **Сетевой стек**: Нативные сокеты BSD / SceNet с одновременной поддержкой двух портов (12813 и 12800)
- **Системные интерфейсы**: SceBgftService, SceAppInstUtil, SceUserService, ScePad, libjbc

## **Ключевые возможности и улучшения**
- **Автоматическая локализация (6 языков)**: Автоопределение языка системы Orbis OS при первом запуске (русский, английский, немецкий, французский, китайский, японский), мгновенное переключение языка кнопкой геймпада и сохранение настроек в энергонезависимой памяти консоли.
- **Двойной сетевой сервер (порты 12813 и 12800)**:
  - Порт **12813** — фирменный расширенный REST API STORM с поддержкой пакетных операций, детальных статусов, отмены и удаления задач.
  - Порт **12800** — полная обратная совместимость со стандартными клиентами flatz Remote Package Installer.
- **Нативная фоновая загрузка (BGFT)**: Использование официального системного загрузчика консоли позволяет продолжать загрузку и установку пакетов даже при сворачивании программы или запуске других игр.
- **Информативный графический интерфейс**:
  - Таблица задач с динамической подсветкой активной строки, показом категории контента (игра, патч, DLC, тема), Title ID, размера, статуса и прогресса в процентах.
  - Отображение официальных иконок контента (`icon0.png`) в таблице с автоматическим кэшированием в оперативной памяти.
  - Полноэкранный просмотр обложки выбранной задачи в разрешении 512x512.
- **Управление очередью**: Контекстное меню для приостановки, отмены и удаления выбранных задач из очереди загрузки.
- **Устранение ошибок и стабильность**:
  - Исправлена критическая ошибка черного экрана при фоновом рендеринге (ликвидирован конфликт наложения фонового изображения).
  - Устранена ошибка переполнения стека и зависания памяти за счет оптимизации буферов задач (`MAX_TASKS = 256`).
  - Автоматическая очистка кэша иконок при завершении или удалении задач.
  - Корректная обработка URL-адресов с экранированными слэшами.

## **Поддерживаемые платформы и системные требования**
- **Игровые консоли**: Sony PlayStation 4 (Fat, Slim, Pro)
- **Версии системного программного обеспечения**: Все версии прошивок с поддержкой homebrew (3.55 – 11.00+)
- **Окружение**: GoldHEN, Mira или аналогичные пейлоадеры с активированным Homebrew Enabler
- **Сетевое подключение**: Локальная сеть Ethernet (рекомендуется) или Wi-Fi 5 ГГц

## **Управление и горячие клавиши**
| Кнопка геймпада | Действие |
| :--- | :--- |
| **Крест (Cross)** | Открыть контекстное меню управления выбранной задачей (Удалить / Отменить) |
| **Круг (Circle)** | Закрыть контекстное меню или вернуться в список задач |
| **Квадрат (Square)** | Полноэкранный просмотр оригинальной иконки выбранного пакета |
| **Треугольник (Triangle)** | Быстрое циклическое переключение языка интерфейса (RU → EN → DE → FR → ZH → JA) |
| **Вверх / Вниз (D-Pad)** | Навигация по списку задач и пунктам меню |
| **L1 / R1** | Быстрая постраничная прокрутка списка задач |

## **Сетевой протокол и интеграция**
Приложение слушает входящие HTTP POST / GET запросы на локальном IP-адресе консоли:

### **Эндпоинты расширенного API (Порт 12813)**
- `POST /api/install` — постановка одного или нескольких пакетов в очередь установки.
  - Тело запроса: `{"type": "direct", "packages": ["http://server/game.pkg"]}`
- `POST /api/task/stop` — остановка активной загрузки по идентификатору задачи.
- `POST /api/task/resume` — возобновление приостановленной загрузки.
- `POST /api/task/cancel` — отмена и удаление задачи из очереди.
- `GET /api/tasks` — получение полного массива текущих задач, статусов и прогресса в формате JSON.
- `GET /api/is_exists` — проверка наличия установленного приложения по Title ID.

### **Эндпоинты совместимости RPI (Порт 12800)**
- `POST /api/install` — стандартный формат flatz Remote Package Installer.
- `POST /api/check_task` — получение статуса задачи в формате RPI.

## **Установка и запуск**
1. Скопируйте установочный пакет `STORM_PS4_PKG_INSTALLER_1.50.pkg` на внешний накопитель USB (файловая система exFAT или FAT32).
2. Подключите накопитель к консоли PlayStation 4.
3. Откройте системное меню **Настройки** → **GoldHEN** → **Package Installer** (или **Debug Settings** → **Game** → **Package Installer**).
4. Выберите файл `STORM_PS4_PKG_INSTALLER_1.50.pkg` и подтвердите установку.
5. Запустите приложение из главного меню консоли. На экране отобразятся IP-адрес консоли и активные порты (12813 и 12800).
